# About Me Page

A small, responsive personal About Me page with a light blue theme and clearly marked placeholders for easy editing.

## Customize it

Open `index.html` and replace text inside square brackets, including:

- `[YOUR NAME]`, `[YOUR INITIALS]`, and `[YOUR PHOTO]`
- The introduction and About Me paragraphs
- Your interests, skills, email address, and social links
- `[YEAR]`

The page is self-contained: all styling is included in `index.html`, so it can be opened directly in a browser or deployed with GitHub Pages.
